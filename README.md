# SmartFood 🍔

SmartFood is a full-stack food ordering web application built using Java Spring Boot and MySQL.

## Features

- User Registration & Login
- JWT Authentication
- Role-based Security
- Restaurant Menu
- Food Search
- Category Filtering
- Food Availability
- Shopping Cart
- Quantity Update
- Remove from Cart
- Checkout
- Order Placement
- Order Confirmation
- Order Tracking
- Order Cancellation
- Admin Dashboard
- Food Management
- Order Status Management

## Technology Stack

### Backend
- Java 17
- Spring Boot 4
- Spring Data JPA
- Spring Security
- JWT
- Maven

### Frontend
- HTML
- CSS
- JavaScript
- Thymeleaf

### Database
- MySQL 8
