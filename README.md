# SmartFood 🍔

SmartFood is a full-stack food ordering web application built using Java Spring Boot, Spring Security, JWT, Thymeleaf, and PostgreSQL.

## 🚀 Live Demo

🔗 **Live Project:** https://smartfood-5.onrender.com

## Features

- User Registration & Login
- JWT Authentication
- Role-based Security
- Restaurant Menu
- Food Search
- Category Filtering
- Food Availability
- Shopping Cart
- Quantity Update
- Remove from Cart
- Checkout
- Order Placement
- Order Confirmation
- Order Tracking
- Order Cancellation
- Admin Dashboard
- Food Management
- Order Status Management

## Technology Stack
